Clés à ajouter manuellement dans l'Info.plist du target NavigoDump (lecteur de carte, étape G).

1. NFCReaderUsageDescription
   Type : String
   Valeur : « Lire et émuler votre passe de transport »
   Explication : description d'usage affichée à l'utilisateur lors de la première utilisation de CoreNFC.

2. com.apple.developer.nfc.readersession.iso7816.select-identifiers
   Type : Array
   Valeur : array contenant la seule chaîne A0000005591010FFFFFFFF8900000100
   Explication : déclare l'AID Calypso que l'app de lecture est autorisée à sélectionner. Ne sert qu'à l'étape G (lecture de la carte physique), inutile pour l'émulation HCE (étape E).

3. UIFileSharingEnabled
   Type : Boolean
   Valeur : true
   Explication : rend le dossier Documents/dumps/ accessible via l'app Fichiers pour récupérer le dump carte-*.txt.

4. LSSupportsOpeningDocumentsInPlace
   Type : Boolean
   Valeur : true
   Explication : permet l'ouverture des documents du dump depuis l'app Fichiers.

Configuration du target :
- Pas d'entitlement HCE (com.apple.developer.nfc.hce absent).
- ReaderView comme vue racine.
- Un seul téléphone ne peut pas lire et émuler en même temps : le test G se fait avec la carte physique, l'émulation est testée après.
